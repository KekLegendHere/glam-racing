# 💖 Glam Racing

Аркадные гонки для телефона: российские машины, розовый закатный асфальт и максимум блёсток.
Играть можно прямо в браузере — ничего ставить не нужно.

## Играть

👉 **https://keklegendhere.github.io/glam-racing/**

Открывается на телефоне, планшете и компьютере. Прогресс сохраняется в браузере.

## Что внутри

- **7 машин** — Веста Спорт, Семёрка, Нива Легенд, Москвич 3, Волга ГАЗ-21, УАЗ Патриот, Аурус Сенат.
  У каждой свои характеристики: скорость, управляемость и радиус магнита для кристаллов.
- **Гараж** — новые машины открываются за собранные 💎.
- **Бонусы** — ⭐ ускорение с неуязвимостью и двойными очками, 💗 дополнительная жизнь.
- **Управление** — веди пальцем по экрану, на компьютере ← → или A/D.

## Как это сделано

Чистый HTML + CSS + JavaScript, вся отрисовка — на `<canvas>`, без библиотек и сборки.
Спрайты машин и фон сгенерированы нейросетью (Codex image generation).

```
index.html      экраны и разметка
styles.css      оформление
js/cars.js      каталог машин и их характеристики
js/game.js      движок гонки: физика, спавн, коллизии, отрисовка
js/app.js       экраны, гараж, сохранение, звук
assets/         спрайты машин и фон меню
```

## Запустить локально

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

Файлы статические — подойдёт любой простой веб-сервер.
